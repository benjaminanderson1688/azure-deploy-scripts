# azure-deploy-scripts

A collection of deployment scripts for Azure-based projects with support for Redis, Python, Docker, and GitHub Actions.

## EditorConfig Setup

This project uses [.editorconfig](.editorconfig) to standardize code formatting across all editors and IDEs.

To configure your editor, run the following command:

```bash
./scripts/configure-editor.sh
```

This will create a .editorconfig file if it doesn't already exist.
